# 🌸 Aniversario de tres meses

Un regalo especial para la mujer más especial

## Comandos de desarrollo
### Previsualizar
```bash
pnpm run dev
```

### Calcular Centro para QR
```bash
uv run find-center packages/QrGenerator/config.yml
```

### Generar QR
```bash
uv run generate-qr packages/QrGenerator/config.yml
```
